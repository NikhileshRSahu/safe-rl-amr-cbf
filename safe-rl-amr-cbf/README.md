An end-to-end implementation of **Safe Reinforcement Learning** applied to Autonomous Mobile Robots (AMRs) operating in dynamic warehouse environments. This project combines a learning-based RL policy with a mathematical **Control Barrier Function (CBF)** safety filter via Quadratic Programming (QP) to guarantee zero-collision navigation.

---

## 🎯 Key Features
* **Kinematic Model:** Unicycle kinematics (Relative Degree 1 model).
* **RL Framework:** Policy trained using **Stable-Baselines3** in a custom **Gymnasium** environment.
* **Real-Time Safety Filter:** Convex optimization implemented using `cvxpy` to solve QP constraints on control inputs ($v, \omega$) in real time.
* **Collision Avoidance:** Guarantees forward invariance of the safe set, filtering out unsafe actions generated by the RL agent near dynamic obstacles.

---

## 📐 System Architecture

1. **Policy Input:** Environmental state & dynamic obstacle positions $\to$ **RL Agent (SB3)**.
2. **Nominal Action:** RL generates nominal velocity command $u_{\text{nom}} = [v, \omega]^T$.
3. **Safety Filter (CBF via `cvxpy`):** Solves QP subject to $B(x) \ge 0$ safety constraints.
4. **Filtered Output:** Safe control action $u_{\text{safe}}$ applied to the AMR.
